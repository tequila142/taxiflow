# TaxiFlow

**Соберите свою систему управления таксопарком без программиста.**

TaxiFlow — интерактивный прототип no-code платформы для небольшого таксопарка: автомобили, водители, пробег, ТО, документы, финансы, автоматизации и конструктор собственных экранов в одном месте.

> Это демо-прототип: все данные демонстрационные и хранятся только в браузере посетителя (localStorage). Сервер и база данных не нужны.

## Что внутри

- **Лендинг** — hero с превью интерфейса, возможности, живая демонстрация автоматизаций, конструктор, тарифы.
- **Онбординг** — «Попробовать за 1 ₽» → количество автомобилей → водители → модули → «Создать рабочее пространство» → Dashboard.
- **Dashboard** — автомобили, водители, на линии, на ремонте, ближайшие ТО, истекающие документы, расходы, задачи, события, графики.
- **Автомобили** — таблица с поиском, фильтрами, сортировкой, добавлением и редактированием; карточка авто с историей пробега, ТО, расходов и документов.
- **Водители** — таблица и профиль: рейтинг, заработок, задолженность, смены, история.
- **Пробег** — ручной ввод и загрузка фото одометра с имитацией распознавания; история изменений; OBD/телематика как будущая функция.
- **Документы, ТО и обслуживание, Финансы, Аналитика, Настройки** (профиль, таксопарк, уведомления, пользователи, тариф, интеграции).
- **Automation Builder** — визуальный конструктор правил WHEN → IF → THEN → AND, 6 шаблонов, тестовый запуск на данных парка.
- **No-Code Конструктор** — сборка своих экранов из блоков (таблица, форма, карточка, календарь, статистика, график, фильтр, уведомление, автоматизация) перетаскиванием.

Демо-данные: 10 автомобилей, 15 водителей, записи ТО, расходы за 6 месяцев, документы с истекающими сроками и готовая автоматизация «ТО по пробегу».

**Попробуйте:** откройте раздел «Пробег» и нажмите «Подставить значение» → «Сохранить пробег». Сработает автоматизация: появится задача «Записать автомобиль на ТО» и уведомление менеджеру.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на github.com (например, `taxiflow`), сделайте его **Public**.
2. Нажмите **Add file → Upload files** и загрузите `index.html` (и этот `README.md`).
3. Откройте **Settings → Pages**, в разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/taxiflow/`.

Можно и без GitHub: просто откройте `index.html` в браузере.

## Технически

- Один файл `index.html`: HTML + CSS + JavaScript, без сборки и зависимостей (шрифт Onest подключается с Google Fonts).
- Графики нарисованы на SVG вручную, без библиотек.
- Адаптивная вёрстка: компьютер, ноутбук, планшет, телефон (на мобильном — выдвижное меню и нижняя навигация, таблицы превращаются в карточки).
- Сбросить демо-данные: **Настройки → Таксопарк → Сбросить демо-данные**.
